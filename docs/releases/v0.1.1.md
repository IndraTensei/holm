A small update to Holm: lyrics in the resting island read properly and cost less.

## Download

| File | What it is |
| --- | --- |
| `Holm_0.1.1_x64-setup.exe` | Installer, about 2 MB, no administrator rights needed. Installing over 0.1.0 keeps your settings and your start-with-Windows choice. |
| `Holm-0.1.1-portable-x64.exe` | The app on its own. Put it anywhere and run it. |

Holm isn't code-signed yet, so Windows SmartScreen may say it "protected your PC". Choose **More info → Run
anyway**.

## What's changed

- **The whole lyric line shows.** With Settings → Look → Resting island set to Lyrics, the last word of a line
  that fits is no longer faded out. A line too long for the island slides once to its end and stays there, so
  you can read how it finishes before the next line comes.
- **Lighter while lyrics play.** The resting island moves to the next line with one timer per line instead of
  checking four times a second, and keeps one width for the whole song instead of resizing on every line.
- **Explained in Settings → About:** the "Microsoft Edge WebView2" processes in Task Manager belong to Holm.
  They sit inside the Holm group on the Processes tab, and quitting Holm closes them.
- **README:** a new "Using it" section covering hover, the bubble beside the island, the shortcut, the tray menu
  and each Settings page.

Requires Windows 10 1809 or later, or Windows 11, 64-bit, with the WebView2 runtime (built into Windows 11; the
installer fetches it if it's missing).
