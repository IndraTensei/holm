Holm can now update itself, and uninstall itself, from Settings → About.

## Download

| File | What it is |
| --- | --- |
| `Holm_0.1.5_x64-setup.exe` | Installer, about 2 MB, no administrator rights needed. Installing over an earlier version keeps your settings. |
| `Holm-0.1.5-portable-x64.exe` | The app on its own. Put it anywhere and run it. |

**Coming from 0.1.4 or earlier?** Those versions can't update themselves yet, so install this one over them
once: download the setup above and run it. From 0.1.5 on, updates take one click.

Holm runs on **Windows 10 (1809 or later) and Windows 11, 64-bit**. macOS and Linux versions are in
development ([#10](https://github.com/IndraTensei/holm/issues/10), [#11](https://github.com/IndraTensei/holm/issues/11)).
It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC" when you run the download.
Choose **More info → Run anyway**.

## New

- **Updates.** Settings → About shows your version and checks for a newer one. **Update** downloads the new
  installer from this page, runs it with a progress window, and Holm opens again by itself, with your settings
  as they were. Holm also checks once a day and shows a short note on the island when a new version is out;
  click the note to go straight to the Update button. The daily check asks GitHub for the latest release and
  sends nothing about you; turn it off under **Check automatically**.
- **Uninstall.** Settings → About → **Uninstall Holm…** opens Holm's uninstaller (it asks whether to delete
  your settings too). The portable exe explains how to remove it and opens its settings folder.
- The portable exe can't replace itself, so it shows a **Download** button instead of Update.
