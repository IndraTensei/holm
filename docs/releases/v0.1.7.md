Answer Claude's questions right on the island, every theme with a look of its own, and your GPU on the System page.

## Download

| File | What it is |
| --- | --- |
| `Holm_0.1.7_x64-setup.exe` | Installer, about 2 MB, no administrator rights needed. Installing over an earlier version keeps your settings. |
| `Holm-0.1.7-portable-x64.exe` | The app on its own. Put it anywhere and run it. |

**On 0.1.5 or 0.1.6?** Settings → About → **Update**, or wait for the note on the island. **On 0.1.4 or earlier?**
Download the setup above and run it once; from then on updates take one click.

Holm runs on **Windows 10 (1809 or later) and Windows 11, 64-bit**. macOS and Linux versions are in
development ([#10](https://github.com/IndraTensei/holm/issues/10), [#11](https://github.com/IndraTensei/holm/issues/11)).
It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC" when you run the download.
Choose **More info → Run anyway**.

## New

- **Answer Claude's questions on the island.** When Claude Code asks a multiple-choice question, the island
  shows the question and its options. Pick one and Claude carries on. Questions that allow several answers
  get checkboxes, several questions come one after another, and a box under the options takes an answer of
  your own. Prefer answering in the terminal or VS Code? Turn off Settings → Agents → **Answer questions in
  Holm** and the island only tells you Claude is waiting.
- **Start a plan from the island.** A plan Claude proposes shows the plan itself, with **Start** and
  **Keep planning**.
- **Themes with a look of their own.** Each of the 15 themes now has its own light and texture, glow, play
  button and bar, and a way of moving when the island opens: Synthwave glows neon over faint scanlines, Nord
  carries an aurora, Editorial sits in candlelight on paper grain, Sakura is soft and round. It's all static
  paint, so the island uses the same CPU as before, resting or busy.
- **Graphics on the System page.** How busy your GPU is, with a sparkline, and how much of its memory is in
  use. PCs with two GPUs get a row for each. The figures match Task Manager and are only read while the page
  is open.

## Fixed

- **Claude's questions no longer show up as Allow and Deny** with raw text instead of the question.
  ([#37](https://github.com/IndraTensei/holm/issues/37))
- **The Agents page fits the island.** With an approval waiting and plan usage on two rows, the bottom of the
