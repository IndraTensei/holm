Games now open with their real logo, a focus timer stays in sight, and updates are safer.

## Download

| File | What it is |
| --- | --- |
| `Holm_0.1.6_x64-setup.exe` | Installer, about 2 MB, no administrator rights needed. Installing over an earlier version keeps your settings. |
| `Holm-0.1.6-portable-x64.exe` | The app on its own. Put it anywhere and run it. |

**On 0.1.5?** Settings → About → **Update**, or wait for the note on the island. **On 0.1.4 or earlier?**
Download the setup above and run it once; from then on updates take one click.

Holm runs on **Windows 10 (1809 or later) and Windows 11, 64-bit**. macOS and Linux versions are in
development ([#10](https://github.com/IndraTensei/holm/issues/10), [#11](https://github.com/IndraTensei/holm/issues/11)).
It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC" when you run the download.
Choose **More info → Run anyway**.

## New

- **Game logos.** The intro that plays when a game starts now leads with the game's own logo, large and lit
  by a glow in its own colours. Holm finds it where the game's launcher registered it with Windows (Riot,
  Steam, EA, Ubisoft, Battle.net and ordinary installers all do), so games whose anti-cheat hides them, like
  Valorant, get their real logo too. Otherwise it reads the game's exe. Nothing is downloaded. A game with
  neither gets a tile with its initials in its colour, and the end-of-game card shows the same mark.
- Settings → Games has Holm's own icon instead of the stock gamepad.

## Fixed

- **A focus timer you start stays in sight.** With music playing and an agent working it used to drop out of
  the resting island. Now it takes the island while it runs or is paused, music or your agent sits beside it,
  and as a thin line the island fills up with the timer's progress.
- Updating on a slow connection no longer gives up after 15 seconds; the download has 10 minutes.
- The installer left in the temp folder after an update is deleted shortly after Holm restarts.
- After a chime, Holm closes its sound output again instead of keeping it open for the rest of the session.

## Security

- Updates check the downloaded installer against the SHA-256 GitHub publishes for it, and won't run a file
  that doesn't match.
