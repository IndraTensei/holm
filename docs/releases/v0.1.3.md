A fix for Make way, and a quieter repository.

## Download

| File | What it is |
| --- | --- |
| `Holm_0.1.3_x64-setup.exe` | Installer, about 2 MB, no administrator rights needed. Installing over an earlier version keeps your settings. |
| `Holm-0.1.3-portable-x64.exe` | The app on its own. Put it anywhere and run it. |

Holm runs on **Windows 10 (1809 or later) and Windows 11, 64-bit**. macOS and Linux versions are in
development ([#10](https://github.com/IndraTensei/holm/issues/10), [#11](https://github.com/IndraTensei/holm/issues/11)).
It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC". Choose **More info → Run
anyway**.

## Fixed

- **Make way no longer flickers.** With the pointer resting a little below the island over a maximized app, the
  island could switch between the full island and the thin line over and over. The zone that counts as "near"
  shrank when the island turned into a line, so the pointer was suddenly outside it and the island came back.
  The zone is now measured from the full island, reaches a little further once the pointer is near, and the
  island only comes back after the pointer has been away for a quarter of a second.
